## 截图脱敏检查清单

提交截图前，请逐项检查：

- [ ] **API Key 已隐藏**：模型配置截图中，API Key 字段应显示为掩码（••••••），不要暴露真实 Key
- [ ] **无真实个人信息**：不包含真实姓名、邮箱、电话、身份证号、家庭住址等
- [ ] **无内部系统信息**：不包含内网地址、内部账号、服务器 IP 等
- [ ] **无敏感对话内容**：演示对话使用示例数据（虚拟人物），不涉及真实隐私
- [ ] **浏览器地址栏无敏感信息**：地址栏不包含 Token、Session ID 等
- [ ] **无其他应用敏感信息**：截图背景中不包含其他应用的敏感内容

### 脱敏方法

如果截图中包含敏感信息，可以：
1. 使用截图工具的马赛克/模糊功能遮盖
2. 重新截图时避开敏感区域
3. 使用图片编辑工具涂抹敏感信息
