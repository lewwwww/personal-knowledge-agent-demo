# 排障指南：回答质量问题的系统排查

> 本文档记录本项目实际踩过的坑与排查方法，全部为可复现的排障步骤。
> 适用场景：Agent 回答质量不达标（一直"记不太清"、答非所问、暴露内部词等）。

---

## 一、高频故障：知识库明明有内容，却永远答"记不太清"

### 现象

- 知识库里确定有的内容（比如实习经历、毕设成果），Agent 答"这个细节我记不太清"
- 反复优化提示词无效，换模型也没用

### 根因

**LLM 节点的变量引用写成了节点标题，而不是节点 ID。**

Dify Chatflow 中，提示词里引用知识检索结果必须写成：

```
{{#1788628000229.result#}}   ← 1788628000229 是检索节点的实际 ID
```

如果写成 `{{#知识检索.result#}}`（节点标题），Dify 不会解析这个变量，
LLM 收到的知识库内容是字面字符串 `{{#知识检索.result#}}`，等于**知识库内容从来没
进过提示词**。模型只能靠自己的记忆和发挥回答，自然频繁"记不太清"。

### 排查三步走（按顺序执行，每步都可独立验证）

#### 第 1 步：验证知识库本身能召回（排除检索侧问题）

- 打开「知识库」→ 该知识库 →「召回测试」页（Hit Testing）
- 输入与故障问题相同的话，观察是否命中多个段落（正常应命中 5-10 段）
- ✅ 命中正常 → 说明文档已向量化、索引健康，问题不在知识库
- ❌ 命中为 0 → 检查分段是否完成、索引状态是否可用

#### 第 2 步：验证检索节点真的执行了（排除节点配置问题）

- 打开「工作室」→ 该应用 →「编排」页
- 点「预览」，输入同一个问题，运行一次工作流
- 点开「知识检索」节点，看面板底部"上次运行"：
  - 状态 SUCCESS 且有 result 内容 → 节点执行正常
  - 状态报错或 result 为空 → 检查节点关联的知识库、Top-K、查询变量（sys.query）

#### 第 3 步：验证 LLM 节点到底收到了什么（这一步必现根因）

- 仍在上一步的预览运行结果中，点开「LLM」节点，查看"上次运行"中的模型输入
- 看提示词里"知识库内容"那一行的实际渲染值：
  - ✅ 渲染成了真实的段落文本 → 引用正确
  - ❌ 渲染成一串 `{{#...result#}}` 占位符原样 → **变量引用写错了节点 ID**
- 修复：把提示词里的引用改为检索节点的实际 ID（节点面板上可复制），保存并发布

> **经验**：这类"跨组件"问题（检索正常、节点正常、LLM 却没收到）用上面的
> 分层验证法 10 分钟内必定位。面试时可以讲成"我用系统化方法逐层隔离"。

## 二、测试方法论：为什么"一题一问 + 开新对话"

### 现象

- Web 应用里连着问多道题，后面的回答越来越差
- 同一道题，换新对话后再问，回答却变好了

### 原因

1. **会话历史污染**：Dify 把多轮对话历史一起发给 LLM，前面答错/答偏的内容会
   进入上下文，带偏后续回答
2. **批量粘贴 = 一个 query**：一次粘贴多道题，知识检索会把整段文字当做一个
   query 去检索，一个都召不回

### 正确测试姿势

1. 点 Web 应用里的「开启新对话」
2. 每轮只发一题，等回答完再发下一题
3. 涉及"为什么没参加秋招"这类时间线问题，单独新开对话测试

## 三、内部词泄漏：回答里出现"定稿/话术/口径"

### 现象

- 被问"为什么没参加秋招"时，Agent 答"这是我的定稿答案""按话术回答"
- 回答里出现"知识库""提前准备"等词——面试官一听就知道这是预设的

### 修复

- 提示词增加**内部词铁律**（v3.2 规则 12）：回答里绝不出现"定稿、话术、口径、
  知识库、检索、提前准备、模板、内部"等词，也不暗示"我是被预设好答案的"
- 时间线类问题（为什么没参加秋招/毕业这段时间在做什么）单独加规则 10：
  按知识库 L7 层口径回答，不承认"提前准备"
- 答不上来的话术从"建议直接问我本人"改为"这个细节我记不太清，我们见面可以展开聊"
  ——前者等于承认"我有一份准备好的答案"，后者像真人临时想不起来

## 四、其他常见问题速查

| 现象 | 检查项 |
|---|---|
| 召回命中太少，回答单薄 | 知识检索节点 Top-K 调大到 8 |
| 检索节点配置保存失败 | 检索节点配置必须走 UI 弹窗改，API 手拼结构会校验报错 |
| 发布后 Web 应用没变化 | 改完要「发布更新」，只保存草稿不生效 |
| 回答太啰嗦/太机械 | 检查规则 3/5，口语化 + 2-4 句话 |
| 软素质问题答不上来 | 确认知识库有 L6 层且每条 Q+A 独立成条 |
| 时间线问题穿帮 | 确认知识库有 L7 层且规则 10 已启用 |
